# Hebrew UI rules
- <html lang="he" dir="rtl">. Check every layout in RTL; direction icons (arrows, chevrons) are mirrored.
- All user-facing text is Hebrew as a native speaker texts family: short, informal. "סיימתי" not "סיום קנייה".
- Numbers and units: 2 ק"ג, 500 גרם, 3 יחידות. In lists the unit follows the name: עגבניות, 2 ק"ג.
- Buttons at least 48 px tall; used one-handed in a supermarket aisle.
- No English in the UI, including placeholders, toasts, errors. Code identifiers stay English.
- System font stack only; no web fonts.
